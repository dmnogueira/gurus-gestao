# Melhor forma de usar + exemplos

Guia longo com os 30 exemplos: [EXEMPLOS.md](./EXEMPLOS.md).

## Melhor forma

1. Comece pelo orquestrador: `conselho: [sintoma + contexto + restrição]`.
2. Não chame Kotter ou Collins por padrão. Deixe o roteamento escolher.
3. Dê contexto: área, tamanho do time, o que já tentou, o que está em jogo.
4. Peça artefato, não palestra.
5. No máximo 3 lentes.
6. Use `guru [nome]` só quando já souber a lente.
7. Feche com plano 7/30/90.

```text
Conselho.
Contexto: [empresa / área / nº de pessoas].
Sintoma: [o que está acontecendo].
Já tentamos: [o que falhou].
Restrição: [prazo, política, budget].
Quero: diagnóstico + quem entra + artefato + plano 7/30/90.
```

## 6 fluxos do orquestrador

**Time calado + estratégia no slide**
`conselho: estratégia no PPT desde março, ninguém fala de risco, comercial perde share.`
→ Speculand + Edmondson + Moran

**40 projetos / 8 pessoas**
`conselho: 40 projetos, 8 pessoas, tudo é prioridade, time exausto.`
→ Nieto-Rodriguez + Crenshaw + Speculand

**Cultura tóxica**
`conselho: ideia morre no comitê, diretor ridiculariza erro, turnover 30%.`
→ Pfeffer + Edmondson + Mull

**Founder gargalo**
`conselho: 35 pessoas, tudo passa por mim, só eu fecho a venda grande.`
→ Power + Burke + Moran

**Guerra de preço**
`conselho: só ganhamos na tabela, produto é bom, não sabemos se é oceano errado.`
→ Kim + Osterwalder + Kotler

**Chão não comprou a transformação**
`conselho: ERP no ar, fábrica criou planilha paralela, mural não aparece no turno da noite.`
→ Kotter + Pardo + Edmondson
